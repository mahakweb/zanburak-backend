
راهنمای کامل نصب SSL (Parspack) روی VPS برای دامنه api.zanburak.ir

====================================================

1. دریافت SSL از Parspack
-------------------------
- از پنل Parspack یک SSL رایگان 3 ماهه فعال کرده‌ای
- بعد از صدور SSL دو فایل مهم دریافت می‌کنی:

1) fullchain.pem  → شامل certificate + chain
2) privateKey.pem → کلید خصوصی (Private Key)

این دو فایل برای نصب روی سرور لینوکسی (VPS) کافی هستند.

====================================================

2. انتقال فایل‌ها به VPS با SCP
--------------------------------
روی ویندوز (PowerShell یا CMD):

اگر پورت SSH پیش‌فرض باشد:
scp E:\fullchain.pem root@SERVER_IP:/etc/ssl/zanburak/
scp E:\privateKey.pem root@SERVER_IP:/etc/ssl/zanburak/

اگر پورت SSH مثلا 9011 باشد:
scp -P 9011 E:\fullchain.pem root@SERVER_IP:/etc/ssl/zanburak/
scp -P 9011 E:\privateKey.pem root@SERVER_IP:/etc/ssl/zanburak/

====================================================

3. ساخت پوشه روی سرور
---------------------
ssh root@SERVER_IP
mkdir -p /etc/ssl/zanburak

====================================================

4. تنظیم Nginx برای Laravel + SSL
----------------------------------

مسیر پروژه:
 /var/www/zanburak-backend

فایل کانفیگ:
 /etc/nginx/sites-available/api.zanburak.ir

----------------------------------------------------

server {
    listen 80;
    server_name api.zanburak.ir;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name api.zanburak.ir;

    ssl_certificate /etc/ssl/zanburak/fullchain.pem;
    ssl_certificate_key /etc/ssl/zanburak/privateKey.pem;

    root /var/www/zanburak-backend/public;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
    }

    location ~ /\.ht {
        deny all;
    }
}

====================================================

5. فعال‌سازی سایت
-----------------
ln -s /etc/nginx/sites-available/api.zanburak.ir /etc/nginx/sites-enabled/

====================================================

6. تست و ریستارت Nginx
----------------------
nginx -t
systemctl reload nginx

====================================================

7. بررسی PHP Version
--------------------
ls /var/run/php/

باید یکی از این‌ها باشد:
php8.3-fpm.sock  → اگر بود همین را استفاده کن
php8.2-fpm.sock  → اگر این بود کانفیگ را اصلاح کن

====================================================

8. نتیجه نهایی
-------------
- http://api.zanburak.ir → ریدایرکت به https
- https://api.zanburak.ir → فعال با SSL
- API Laravel در مسیر public اجرا می‌شود

====================================================

اگر خطا داشتی:
- nginx -t
- tail -n 50 /var/log/nginx/error.log
